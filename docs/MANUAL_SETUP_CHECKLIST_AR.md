# RUVEN — قائمة الإعدادات اليدوية المتبقية

آخر تحديث: 2026-10-21

هذه القائمة تميّز بين ما أُنجز آلياً وما يحتاج تدخلاً من مالك المشروع. لا تضع أي مفتاح `service_role` في التطبيق أو GitHub.

## أُنجز — لا تكرره

- [x] ربط ChatGPT بمشروع Supabase `ruven-school-app` (الحالة كانت ACTIVE_HEALTHY).
- [x] تطبيق مخطط قاعدة البيانات والترحيلات على قاعدة البيانات الحية.
- [x] التحقق من وجود جداول `profiles`, `class_sections`, `school_items`, `teacher_subjects`, `report_updates`.
- [x] التأكد من أن دالة `public.rls_auto_enable()` لا يمكن تنفيذها بواسطة `anon` أو `authenticated` أو `PUBLIC`.
- [x] تثبيت حساب المالك الحالي بالبريد المحدد في المشروع؛ لا تنشئ حساب مالك ثانياً.
- [x] نشر Edge Function `owner-create-account` مع التحقق من جلسة المستخدم وصلاحية المالك على الخادم.
- [x] إضافة واجهة إنشاء الحسابات وإدارة الشعب إلى فرع `feature/ruven-announcements`.

## المطلوب يدوياً من المالك

1. [ ] **إضافة أسرار GitHub للبناء:** افتح مستودع [RUVEN](https://github.com/mostafa0782/RUVEN) ثم Settings → Secrets and variables → Actions → New repository secret. أضف:
   - `SUPABASE_URL` = رابط مشروع Supabase، ويبدأ بـ `https://`.
   - `SUPABASE_PUBLISHABLE_KEY` = مفتاح Supabase Publishable الخاص بالمشروع (أو مفتاح `anon` القديم إذا كان هذا ما يعرضه مشروعك).
   
   لا تستخدم `service_role` أو `secret key` في هذين الحقلين.

2. [ ] **انتظار نجاح بناء Android:** افتح تبويب Actions في GitHub، وتأكد أن أحدث تشغيل على `feature/ruven-announcements` نجح في الاختبارات وبناء APK. لا تعتبر التطبيق جاهزاً قبل ذلك.

3. [ ] **تنزيل APK وتجربته على التابلت:** من تشغيل Actions الناجح، نزّل artifact باسم `RUVEN-debug-apk` وثبّته. سجّل الدخول بحساب المالك، وتحقق من ظهور إدارة الحسابات وإدارة الشعب.

4. [ ] **اختبار إنشاء حساب تجريبي:** من إدارة الحسابات أنشئ حساباً تجريبياً ببريد تملكه وكلمة مرور مؤقتة لا تقل عن 8 أحرف، ثم سجّل الخروج وجرّب الدخول به. احذف الحساب التجريبي أو غيّر دوره/شعبته بعد الاختبار حسب الحاجة. لا تستخدم بيانات طلاب حقيقية في الاختبار.

5. [ ] **إدخال حسابات المدرسة الفعلية لاحقاً:** بعد نجاح الاختبار، أنشئ حسابات الموظفين والطلاب المطلوبة وعيّن الأدوار والشعب الصحيحة A–F. أنشئ الشعبة فقط عند الحاجة، ولا تفتح شعبة فارغة بلا داعٍ.

## تنبيه عن الحالة الحالية

- تغييرات الواجهة والخادم محفوظة على فرع `feature/ruven-announcements` وليس على `main`.
- نجاح نشر Edge Function لا يثبت وحده أن تدفق إنشاء الحساب اختُبر من داخل APK؛ هذا الاختبار ما زال مطلوباً.
- أقسام الواجبات والتحاضير والجدول والإعلانات ما زالت تتضمن أجزاءً محلية تجريبية. لا تعلن التطبيق للمدرسة قبل ربط هذه الوظائف والتحقق من صلاحيات قاعدة البيانات.
