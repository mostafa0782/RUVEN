# RUVEN — قائمة الإعدادات والاعتماد المتبقية

آخر تحديث: 2026-11-21

## ما تم التحقق منه

- [x] قاعدة Supabase الحية تحتوي 15 جدولاً عاماً للتطبيق، وRLS مفعّل على جميعها.
- [x] سياسات التخزين الخاصة بالكتب والمجسمات تمنع رفعها من غير الإدارة.
- [x] وظائف إنشاء الحساب وتغيير الدور تتحقق من JWT وصلاحية المالك على الخادم.
- [x] مفتاح service_role غير موجود في تطبيق Android، وصلاحياته على الجداول العامة مقيدة.
- [x] CI سابق اجتاز اختبارات الوحدة وبناء APK والتحقق من التوقيع.
- [x] تغييرات تشفير refresh token، تقييد FileProvider، والتحقق من حجم/مصدر التحديث محفوظة على الفرع؛ يلزم انتظار CI الأحدث قبل اعتمادها.

## المطلوب قبل إطلاق المدرسة

1. [ ] **انتظار نجاح أحدث CI:** افتح [GitHub Actions](https://github.com/mostafa0782/RUVEN/actions) وتحقق أن أحدث تشغيل على `feature/ruven-announcements` نجح على نفس commit الحالي. لا تستخدم artifact من تشغيل أقدم على أنه أحدث نسخة.
2. [ ] **تفعيل حماية كلمات المرور المسرّبة:** من إعدادات Supabase Auth، فعّل Leaked Password Protection إذا كانت متاحة لخطة المشروع، ثم أعد فحص Security Advisor. هذا الإعداد لا يتم عبر SQL.
3. [ ] **اختبار عملي على جهاز Android:** اختبر تسجيل الدخول، ترحيل جلسة الدخول القديمة إلى التخزين المشفر، استعادة الجلسة، تسجيل الخروج، الإشعارات، رفع/قراءة المرفقات، وفتح ملف التحديث وتثبيته.
4. [ ] **تثبيت مفتاح التوقيع:** تأكد من إعداد أسرار GitHub الأربعة: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. لا تغيّر المفتاح بعد توزيع النسخة.
5. [ ] **اعتماد سياسة الخصوصية:** تحتاج موافقة المدرسة، وبيانات اتصال رسمية، ومدد احتفاظ وحذف، وإشعاراً مناسباً لأولياء أمور الطلبة القاصرين.
6. [ ] **تأكيد هوية المدرسة قبل تعدد المدارس:** لا تضف مدرسة ثانية إلى مشروع Supabase الحالي قبل اعتماد المدرسة الحالية وربط كل السجلات بعضويات مدرسية واختبار العزل بين مدرستين.
7. [ ] **اختبار النسخة الرسمية:** إصدار 0.1.x يجب أن يكون رقم patch فيه أعلى من رقم أحدث تشغيل Android CI على commit نفسه؛ سيرفض workflow الإصدار إذا كان `versionCode` غير قابل للتحديث.

## تنبيهات

- الفرع الحالي هو `feature/ruven-announcements`، وPull Request رقم 1 ما زال غير مدمج.
- لا تعتبر التطبيق جاهزاً للإطلاق لمجرد نجاح البناء؛ يلزم اختبار فعلي للأدوار والجلسات والتحديثات.
- لا تضع مفتاح service_role أو بيانات طلاب حقيقية في GitHub أو ملفات Android.
- سياسة الخصوصية والشروط الحالية مسودات وليستا اعتماداً قانونياً أو وزارياً.
